# Vocab Arena – Englisch-Vokabeltrainer für Paul

Eine reine Browser-App ohne Server und ohne Build-Schritt, optimiert fürs iPad.

## Vokabeln
Alle Vokabeln stehen in `vocab.js`. Jede Vokabel sieht so aus:
`{ unit: "Unit 3", en: "to explore", de: "erkunden, erforschen", example: "Let's explore the castle." }`
- Mehrere richtige Antworten trennst du mit `,` `;` oder `/`.
- Optionale Teile kommen in Klammern, z. B. `(to) go`.
- Die Units erscheinen automatisch in der Auswahl.

## Funktionen
- Auswahl von Unit, Richtung (EN→DE / DE→EN), Spielmodus (Schreiben, Auswahl, Lückentext, Mix) und Anzahl der Fragen
- Tippfehler-Toleranz: Antworten, die „fast richtig“ sind, zählen als richtig und zeigen die richtige Schreibweise an
- Aussprache über die Sprachausgabe des iPads
- Wiederholsystem: Falsch beantwortete Wörter kommen öfter dran, dazu der Modus „Nur schwierige Wörter“
- XP, Level, Trophäen, Ränge, Abzeichen, Combo und Tages-Serie
- Auswertung mit Note (1–5), Fehlerliste und einem Button zum Üben der Fehler
- Alle Tests bleiben unter „Meine Tests“ gespeichert (lokal im Browser), mit Wiederholen-Funktion
- Karteikarten zum Lernen
- Sicherung exportieren und importieren (Einstellungen)
